## Что умеет сервис (текущий этап — скелет)

- Загрузка файла через веб-страницу.
- Возврат JSON с конспектом (пока заглушка вместо реальной обработки).
- Проверка связи с локальной моделью через эндпоинт `/api/model-check`.

## Стек

| Часть | Что используем |
|---|---|
| Backend | Python, FastAPI, Uvicorn |
| Frontend | HTML-форма |
| Локальная модель | Ollama (Qwen2.5:3B) |
| База данных | пока список в памяти (заглушка) |

## Как запустить

## 1. Установить Ollama и скачать модель

- Скачать Ollama: https://ollama.com
- Скачать модель:
  ```bash
  ollama pull Qwen2.5:3B
  ```

## 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv venv
source venv/bin/activate.fish      # для fish
# или: source venv/bin/activate    # для bash/zsh
# или: venv\Scripts\activate       # для Windows cmd
pip install -r requirements.txt
```
## 3. Запустить сервер из корня проекта

```bash
uvicorn backend.main:app --reload
```

## 4. Открыть в браузере

- Главная страница с формой: http://127.0.0.1:8000
- Документация API (Swagger): http://127.0.0.1:8000/docs
- Проверка связи с моделью: http://127.0.0.1:8000/api/model-check

## Структура репозитория

```
backend/
  __init__.py     пакет Python
  main.py         API: эндпоинты и связка слоёв
  extract.py      извлечение текста из файла (пока заглушка)
  llm.py          создание конспекта + запрос к Ollama
  storage.py      хранение результатов (пока список в памяти)
frontend/
  templates/
    index.html    форма загрузки файла
docs/             паспорт проекта, устав, требования, диаграммы
requirements.txt  зависимости Python
.gitignore        что не попадает в репозиторий
```

## Что пока заглушки

- backend/extract.py — извлечение текста из DOCX/PDF/TXT.
- backend/llm.py → summarize() — создание конспекта моделью.
- backend/storage.py — хранение (список в памяти, без БД).

## Статус

Скелет работает от начала до конца: загрузка файла → заглушка извлечения → заглушка конспекта → JSON. Реальный запрос к локальной модели проверяется отдельным эндпоинтом.
